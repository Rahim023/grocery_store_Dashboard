# Grocery Store Data Analysis Dashboard

## Project Overview

This project presents an interactive Grocery Store Data Analysis Dashboard developed using Microsoft Excel. The analysis is based on transactional and customer data from 1997 and 1998. The primary objective is to convert raw retail data into structured insights that support performance evaluation and business decision-making.

The dashboard integrates data cleaning, transformation, pivot tables, pivot charts, KPI development, and slicers to enable multi-dimensional analysis.

---

## Project Objectives

* Compare sales performance between 1997 and 1998
* Measure overall revenue and profitability
* Analyze customer demographics and segmentation
* Evaluate regional and country-level distribution
* Design a structured and interactive Excel dashboard

---

## Key Performance Indicators (KPIs)

* Total Revenue: $1,764,546.44
* Average Profit per Sale: $3.90
* Customer Average Spending: $6.54

---

## Sales Performance Analysis

The dashboard includes a monthly sales trend comparison between 1997 and 1998. The analysis indicates higher sales performance in 1998 across most months, with noticeable growth toward the final quarter. This comparison supports year-over-year performance evaluation and trend identification.

---

## Customer Demographics

### Age Group Distribution

* Middle-aged Adults: 43%
* Adults: 28%
* Senior Adults: 27%
* Teen: 2%

The majority of customers belong to working-age segments, which represent the primary revenue-driving group.

### Occupation Categories

* Professional: 33%
* Skilled Manual: 27%
* Manual: 24%
* Management: 14%
* Clerical: 2%

The customer base is largely composed of professionals and skilled workers.

### Marital Status and Gender

The analysis compares married and single customers by gender, showing a relatively balanced distribution with slightly higher representation among married customers.

---

## Geographic and Regional Insights

* The USA represents the highest number of customers compared to Canada and Mexico.
* Regional department performance is strongest in the North West and South West regions.

This geographic breakdown supports location-based performance evaluation.

## Technical Implementation

The dashboard was developed using:

* Microsoft Excel
* Pivot Tables and Pivot Charts
* KPI Cards
* Slicers (Education, Year, Country)
* Data Cleaning and Transformation Techniques

The interactive slicers enable dynamic filtering and multi-level analysis.
